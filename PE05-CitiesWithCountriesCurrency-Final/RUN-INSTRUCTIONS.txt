PE05 - Cities with Countries and Currency

1. Extract this project folder.
2. Open a terminal inside PE05-CitiesWithCountriesCurrency.
3. Install all declared packages:
   npm install
4. Start locally:
   npx expo start

For the browser version:
   npx expo start --web

For Expo Go through a tunnel:
   npx expo start --tunnel

If Expo reports dependency mismatches:
   npx expo install --fix
   npx expo start --clear
